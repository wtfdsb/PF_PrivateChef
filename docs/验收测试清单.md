# 上线前验收测试清单

> 用法：找一部手机当「客户」，厨师手机当「商家」，照着打勾。每项通过的画 ✓，有问题的记录现象。

## 一、客户侧（小程序真机）

### 首页
- [ ] 打开加载出云端真实数据（不是假数据；无"服务开小差了"）
- [ ] 厨师头像/案例图（放图后生效，未放图显示金色占位不裂图）
- [ ] 「按场合来选」7 个入口 → 点进去各自详情页内容完整
- [ ] 「最近能约的日子」可点选跳预约页
- [ ] 「常点的三档」显示「面议」
- [ ] 底部「电话咨询」拨打 15903697992
- [ ] 悬浮「客服」按钮能点开客服会话

### 预约流程（核心）
- [ ] 服务详情页「约这个服务」→ 预约页顶部显示「想约的服务：xxx」
- [ ] 人数快捷选（6/8/10/12/16/20）点击生效
- [ ] 口味忌口、特殊需求标签（摆盘仪式等）可填
- [ ] 提交后出现「预约已提交」成功页 + 订单号可复制
- [ ] 重复提交同一日期餐次 → 被拦截提示
- [ ] 「我的预约」能看到刚提交的订单（时间线在"已提交"）

### 在线客服
- [ ] 客户点「客服」发消息 → 厨师在微信「客服小助手」收到并回复 → 客户能看到回复

## 二、商家侧（手机浏览器/微信打开 https://…/admin/）

- [ ] 登录 admin / admin888
- [ ] 顶部统计条数字正确
- [ ] 新订单出现在「预约单」列表，信息完整（电话/地址/忌口/需求/服务项目）
- [ ] 点「📞 联系客户」能拨号
- [ ] 「确认接单」→ 客户「我的预约」时间线变"已确认"
- [ ] 客户微信收到「已确认定档」客服消息（前提：客户 48h 内联系过客服）
- [ ] 「标记已收」定金 → 客户端显示"定金已收 ✓"
- [ ] 「制作中」→「完成」→ 客户端时间线走完
- [ ] 档期页：点午/晚宴切换 可约/已满/关闭
- [ ] 页面挂后台 60 秒自动刷新 + 来新单提示音
- [ ] 「测试推送」→ 微信收到测试消息
- [ ] 订单卡「✉ 发客服消息给客户」可发模板消息

## 三、微信推送（商家微信）

- [ ] 客户提交预约 → 微信秒收「新预约提醒」（含电话/地址/忌口）
- [ ] PushPlus 通道（已实名）为主，Server酱兜底

## 四、数据一致性抽查

- [ ] 云数据库 booking 表能看到对应订单（后台操作后状态/定金同步变化）
- [ ] 后台改档期状态 → 客户预约页该日期餐次不可选

- [ ] 小程序备案（公众平台提交，免费，1-2 周）
- [ ] 提审：类目、隐私保护指引、图片不侵权
- [ ] 改后台密码 admin888
- [ ] 体验版发布：上传代码 → 选为体验版 → 加体验成员（≤15 人）
- [ ] 正式发布（审核通过后）
