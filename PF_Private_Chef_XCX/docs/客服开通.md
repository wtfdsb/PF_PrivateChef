# 小程序在线客服开通步骤

小程序里已经加好了「在线客服」按钮（首页悬浮「客服」圆钮、服务说明页、案例详情页、预约成功页），
用的是微信官方 `open-type="contact"` 客服会话。**需要在微信公众平台做一次配置才生效**，步骤如下：

## 1. 添加客服人员（把厨师绑定成客服）

1. 电脑浏览器登录 <https://mp.weixin.qq.com>（小程序管理员微信扫码）
2. 左侧菜单：**功能 → 客服**
3. 点「添加客服人员」→ 输入**厨师的微信号**（让他提前确认好，就是别人加他好友用的那个）
4. 厨师在微信里会收到「客服小助手」小程序的通知，点进去**确认绑定**

> 新版后台如果展示的是「微信客服」，先点「开通」即可，再绑定接待人员，
> 同样绑定厨师的微信号。

## 2. 测试

1. 微信开发者工具里点「在线客服」按钮（模拟器会提示"请使用真机"属正常）
2. 真机预览扫码 → 点客服按钮 → 发一条消息
3. 厨师在微信「客服小助手」小程序里收到并回复，客户在小程序里能看到

## 3. 规则说明（必须知道）

- **48 小时窗口**：客户主动发消息后的 48 小时内，厨师可以回复；超时后只能等客户再发消息
- 客户从不同页面点「在线客服」进入的都是同一个会话
- 客服小助手里可以设置**快捷回复**（常用语：定金规则、档期说明等）

## 4. 以后能做的（可选）

- 接入自动回复机器人（客户常见问题秒回）
- 客户提交预约后，服务端可以主动给客户发一条客服消息确认（需客户 48h 内先发起过会话）
