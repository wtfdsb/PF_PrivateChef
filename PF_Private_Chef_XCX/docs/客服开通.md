# 小程序在线客服开通步骤

小程序里已经加好了「在线客服」按钮（首页悬浮「客服」圆钮、服务说明页、案例详情页、预约成功页），
用的是微信官方 `open-type="contact"` 客服会话。**需要在微信公众平台做一次配置才生效**，步骤如下：

## 1. 添加客服人员（把厨师绑定成客服）

1. 电脑浏览器登录 <https://mp.weixin.qq.com>（小程序管理员微信扫码）
2. 左侧菜单：**功能 → 客服**
3. 点「添加客服人员」→ 输入**厨师的微信号**（让他提前确认好，就是别人加他好友用的那个）
4. 厨师在微信里会收到「客服小助手」小程序的通知，点进去**确认绑定**

> 新版后台如果展示的是「微信客服」，先点「开通」即可，再绑定接待人员，
> 同样绑定厨师的微信号。

## 2. 测试

1. 微信开发者工具里点「在线客服」按钮（模拟器会提示"请使用真机"属正常）
2. 真机预览扫码 → 点客服按钮 → 发一条消息
3. 厨师在微信「客服小助手」小程序里收到并回复，客户在小程序里能看到

## 3. 规则说明（必须知道）

- **48 小时窗口**：客户主动发消息后的 48 小时内，厨师可以回复；超时后只能等客户再发消息
- 客户从不同页面点「在线客服」进入的都是同一个会话
- 客服小助手里可以设置**快捷回复**（常用语：定金规则、档期说明等）

## 4. 服务端自动消息（已接入代码）

后端已经接好「发送客服消息」接口，两种触发方式：

### 自动触发（无需操作）
客户在微信登录状态下提交预约、且 48 小时内联系过在线客服时，会自动收到：

| 时机 | 内容 |
|---|---|
| 提交预约 | 「预约已收到：X月X日 午宴，8人…请留意来电」 |
| 确认定档 | 「您的预约已确认定档，届时准时上门」 |
| 取消预约 | 「您的预约已取消，如需改期欢迎联系」 |
| 完成服务 | 「感谢您的信任，期待再次为您掌勺」 |

### 厨师手动发送（商家后台）
管理后台订单卡片里「✉ 发客服消息给客户」：一键模板（确认定档/沟通菜单/师傅出发）+ 自定义内容。
发送失败时后台会提示原因（最常见：客户超 48 小时未联系客服）。

### 生效前提
- 后端配置真实 `WX_APPID` / `WX_SECRET`（application.yml 环境变量，未配置时自动降级跳过，不影响其他功能）
- 客户下单时已完成微信登录（小程序已做静默登录，客户无感知）

## 5. 以后能做的（可选）

- 给客户发图片消息（菜单照片等，用临时素材接口）
