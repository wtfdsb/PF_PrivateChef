## 拍照建议（直接影响转化率）

- **整桌全景**：菜上齐后的俯拍/斜拍，光线要亮
- **招牌菜特写**：海鲜姿造冰盘、东星斑这类"硬菜"必须有大特写
- **带人的场景**：客人在座的热闹氛围照比纯菜品更有说服力
- 手机原相机拍，不要加滤镜太重的美颜

## 注意

- 支持 jpg / png，**单张建议 < 300KB**（图片太大会拖慢小程序加载，可用微信/美图压缩后放入）
- 本目录图片默认**不进 git**（`.gitignore` 已排除），只在你本机生效
- 上线前：把图片上传到图床/COS，在数据库 `work_case.images` 里换成 https 地址，
  这样图片不占小程序包体积、加载更快
